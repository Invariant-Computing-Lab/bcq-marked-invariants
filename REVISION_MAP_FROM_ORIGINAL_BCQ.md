# Revision Map from the Original BCQ Formulation

| Original element | Revised status | Reason |
|---|---|---|
| Three D1-branes directly identified with a quark | Downgraded to a microscopic hypothesis | A stack multiplicity can organize a `U(3)` sector, but a D1 world-volume is 1+1 dimensional and does not by itself produce 3+1D QCD. |
| Chan-Paton entries `lambda_ij` | Removed from invariant set | Gauge-basis dependent; use conjugacy/representation/Casimir data. |
| `U(3)` stack structure | Retained conditionally | Standard D-brane mechanism, but a 4D effective embedding remains required. |
| `I_ab = 3` as explanation of three generations | Retained as a **derived** topological condition | Robust under admissible transformations, but exhaustive testing shows strong non-uniqueness. |
| Hypercharge coefficients `c_i` | Removed from invariant set | Basis-dependent coordinates; the functional `Y` is invariant. |
| Fractional charge trial-and-error calculations | Replaced by `A c = y` constraint system | Cleaner, falsifiable, and separates basis covariance from physical consistency conditions. |
| Raw mass `M`, brane separation `L`, `alpha'` | Moved to unit-dependent/moduli layer | Use dimensionless `mu^2 = alpha' M^2` and `ell = L/sqrt(alpha')`. |
| Linear stretched-string potential as confinement proof | Claim removed | A microscopic linear energy is not a proof of four-dimensional nonperturbative QCD confinement. |
| Full DBI/Polyakov/mode-expansion detail in main logical core | Moved to realization/background layer | These formulas may instantiate the model but do not define its minimal identity class. |
| Compactification `M(Y_6)` as if established | Conditional only | Algebraic/Calabi-Yau structure and required consistency conditions have not been demonstrated. |

The revised manuscript is therefore intentionally narrower: it presents a quotient-invariant formalization and a falsification program rather than claiming a completed physical derivation of the Standard Model quark sector.
