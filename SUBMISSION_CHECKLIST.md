# Submission Checklist

Before submission to a specific journal:

- [ ] Select the target journal and apply its exact LaTeX class/reference style.
- [ ] Verify the journal's current scope and article type; the present package is journal-neutral.
- [ ] Decide whether the original BCQ manuscript should be cited as a public preprint/DOI or described as prior internal work, and update Reference 8 accordingly.
- [ ] Add the definitive repository/DOI for the reproducibility package after archiving it.
- [ ] Complete funding, competing-interest, and AI/tool-use disclosures according to the target journal's current policy.
- [ ] Add any required author affiliation details and corresponding-author designation.
- [ ] Do not upgrade synthetic validation language into physical validation language.
- [ ] If a physical BCQ claim is retained, add an explicit compactification, four-dimensional effective embedding, global consistency analysis, and phenomenological constraints.
- [ ] Run the package from a clean environment and preserve the generated `run_metadata.json`.
- [ ] Confirm all figures are accepted in the journal's preferred vector/raster formats.
